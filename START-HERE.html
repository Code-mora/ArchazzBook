Cara Upload Buku Pertama

1 Klik "Author Login" di navbar
2 Masukkan username wazz dan password wazzhere
3 Kamu akan otomatis masuk ke Dashboard
4 Klik tombol "Add New Book"
5 Isi form dengan:
  • Judul buku
  • Cover image (PNG/JPG, max 5MB)
  • Preview text (deskripsi singkat)
  • Full story (cerita lengkap)
  • Jumlah halaman
6 Klik "Publish Book" dan bukumu langsung muncul di homepage!

Cara User Membaca

Super Simple!

  1. Buka website ArchazzBook
  2. Scroll dan lihat koleksi buku
  3. Klik card buku untuk lihat detail
  4. Klik "Read Now" - langsung bisa baca!
  5. Nikmati dengan fitur font size & dark mode

Struktur File

  • index.html - Homepage dengan gallery buku
  • dashboard.html - Dashboard author (protected)
  • reader.html - Halaman baca buku
  • styles.css - Semua styling
  • app.js - Logika aplikasi
  • dashboard.js - Fungsi dashboard

Penyimpanan Data

Semua data disimpan di browser localStorage:

  • Buku yang kamu buat
  • Sesi login author
  • Persisten sampai cache dibersihkan

Tip: Untuk production, sebaiknya pakai database backend (MySQL, MongoDB, dll)

Kustomisasi

Personalisasi platform-mu:

  • Warna: Edit CSS variables di styles.css
  • Branding: Ganti "ArchazzBook" dengan nama lain
  • Buku Awal: Edit array books di app.js
  • Author Login: Sudah diset ke wazz / wazzhere

Keamanan
